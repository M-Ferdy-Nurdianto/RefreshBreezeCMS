# Project Roadmap & Backlog

This document tracks planned improvements, technical debt, and feature requests for the Refresh Breeze platform.

## High Priority

- [ ] Automated Order Webhook Notifications: Connect order status updates to Discord / Telegram webhooks for instant admin alerts.
- [ ] Bulk Image ZIP Exporter: Enable downloading all payment proofs and Cheki receipts for a specific event in a single archive.
- [ ] Customer Order Lookup Portal: Allow fans to check order status and download receipts using their phone number or Instagram handle without admin assistance.

## Medium Priority

- [ ] Advanced Inventory Alerts: Low-stock email notifications for limited-edition merchandise and Cheki ticket caps.
- [ ] Fan Loyalty Point System: Accumulate points per Cheki purchase redeemable for exclusive digital photocards.
- [ ] Multiple Admin Roles: Granular access control (Superadmin, Cashier OTS, Merchandise Staff).

## Low Priority / Optimizations

- [ ] Next-Gen Image Formats: Explore AVIF support alongside WebP.
- [ ] Automated Database Backups: Scheduled pg_dump exports to cold storage.
- [ ] Offline PWA Support: Cache active shop items for poor connectivity at event venues.
